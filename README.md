# SignSpark

**A free, game-style web app for learning American Sign Language (ASL).**

SignSpark teaches hearing beginners the ASL alphabet, numbers 0–10 and 59 everyday signs through short lessons, spaced-repetition flashcards, a word of the day and practice games. It runs in any modern browser on a phone, tablet or computer, works offline, and needs no account.

Built for the 2026 Congressional App Challenge.

## Features

| Area | What it does |
|---|---|
| **Learning path** | 9 units, 35 lessons: fingerspelling A–Z, numbers, greetings, family, feelings, questions, everyday life, and Deaf culture. Lessons unlock one after another. |
| **10 exercise types** | New-sign cards, "what does this sign mean?", "find the handshape", "choose the description", matching pairs, reading fingerspelled words, spelling words with handshape tiles, ASL sentence order, sign-it-yourself, and true/false culture questions. |
| **No-fail lessons** | Mistakes come back at the end of the lesson until you get them right. No hearts, no lives. |
| **Flashcards** | Spaced repetition (a simplified SM-2 algorithm) schedules each card right before you would forget it. Decks: My signs, Alphabet, Numbers, Word signs. |
| **Word of the day** | A new sign every day, with an example sentence and a quick practice drill. Every word appears once before any repeats. |
| **Practice** | Smart review of your most-missed signs, a fingerspelling speed reader, a 60-second lightning round, a sentence builder, a Deaf culture quiz, and "fingerspell anything" for your own name. |
| **Dictionary** | Search and browse all 96 signs, with links to videos of real signers. |
| **Progress** | XP, daily goal, day streak, a weekly chart, a 4-week activity calendar and 16 badges. |
| **Settings** | Left- or right-handed drawings, a mirrored "your own hand" view, 6 hand colors, light/dark theme, reduced motion, and a demo mode that opens every lesson. Backup codes move progress between devices. |

### How the signs are shown

Every hand drawing in the app is generated by code. Each of the 45 handshapes is a small recipe (which fingers are straight, curled or bent, where the thumb goes, how the hand is turned), and `src/render/hands.js` draws it as an SVG. Word signs pair the handshape with a body map that marks the **location**, draws the **movement** with arrows and shows the **facial expression**, following the parameters ASL teachers use: handshape, location, movement, palm orientation and face.

### Designed for this subject

- **No sound needed.** Feedback is visual (and optional vibration), because an ASL app should work for Deaf and hard-of-hearing users too.
- **Left-handed signers** see every drawing mirrored.
- **Respect for Deaf culture.** The app reminds learners that ASL is the language of the Deaf community, teaches etiquette, and points to Deaf-led organizations and real signers.

## Run it

**Quickest:** open `dist/index.html` in any browser. It is a single file with everything inside it, so it also works offline or from a USB drive.

**From the source code:**

```bash
python3 -m http.server 5173    # or: npm run dev
# then open http://localhost:5173
```

(ES modules need a web server; opening `index.html` straight from the disk will not work. `dist/index.html` does.)

**Rebuild and test** (needs Node.js 18 or newer):

```bash
npm install      # installs esbuild, the only dependency (used for building)
npm test         # runs the unit tests
npm run build    # writes dist/index.html
```

**Publish a free link with GitHub Pages:** push this folder to a public GitHub repository, then go to **Settings → Pages → Deploy from a branch → main / (root)**. The site appears at `https://<your-username>.github.io/<repo-name>/`.

## Project structure

```
index.html              development entry point (loads src/main.js)
build.mjs               bundles everything into dist/index.html
dist/index.html         the finished app in one file
src/
  main.js               app shell, navigation, start-up
  styles.css            all styles, light and dark themes
  data/                 content: signs, handshapes, lessons, sentences, facts, spelling words
  render/hands.js       draws handshapes as SVG from their recipes
  render/body.js        draws the body map: location, movement arrows, facial expression
  engine/lesson.js      builds lessons and practice sessions (pure functions)
  core/                 saved state, XP and streaks, spaced repetition, badges, dates
  ui/                   shared pieces: icons, dialogs, toasts, sign pictures, theme
  views/                one file per screen, plus the lesson player and exercise types
tests/                  unit tests (Node's built-in test runner)
```

See **CODE_GUIDE.md** for a walkthrough of how everything works.

## Technology

- Plain JavaScript (ES modules), HTML and CSS. No framework.
- SVG for every drawing, generated at runtime. No image files.
- `localStorage` for saving progress on the device. No server, no accounts, no tracking.
- [esbuild](https://esbuild.github.io/) to bundle the single-file build.
- Node's built-in `node:test` for unit tests (19 tests).
- Fonts: Bricolage Grotesque, Lexend and DM Mono from Google Fonts (SIL Open Font License). The app falls back to system fonts offline.

## Accessibility

Keyboard shortcuts in lessons (1–4 to answer, Enter to check and continue, Escape to quit), visible focus outlines, screen-reader labels, respect for the system "reduce motion" setting, light and dark themes, and layouts that work from small phones to large screens.

## About the content

Sign descriptions follow common ASL usage, but signs vary by region and community, and a written description cannot replace watching a fluent signer. Every sign in the dictionary links to videos of real signers. Please learn from Deaf teachers and the Deaf community whenever you can.
